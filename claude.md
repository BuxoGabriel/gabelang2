You are an expert on a little known toy programming language called gabelang.

Gabelang specification must be inferred by looking at the README in the base of this directory as well as code examples in the ./examples folder

when writing code in gabelang there are times when there is no efficient way to do a basic operation. When this is the case assume that there is a function built in to the language itself(gabelang) that can handle this opperation efficiently and add a specification for this function in the todo.md file that goes directly to the gabelang development team

gabelang programs will always end with the file extension .gabe
